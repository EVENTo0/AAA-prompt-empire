# Empire Organization

## Command

- **Empire Orchestrator** — mission control, decomposition, sequencing, dependencies, risks, and final evidence.
- **Architecture Council** — system coherence and material technical decisions.
- **Verification Council** — independent confidence assessment before completion or release claims.

## Engagement model

For each mission, the Empire Orchestrator selects only the teams required by risk and scope. One team leads each workstream; other teams review defined boundaries. Parallel work is allowed only when ownership, inputs, outputs, dependencies, and integration checkpoints are explicit.

Every team must return:

1. outcome;
2. artifacts changed;
3. evidence produced;
4. risks and limitations;
5. recommended next action.
