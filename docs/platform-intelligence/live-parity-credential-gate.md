## Required repository secrets

The manual `Empire Live Proof Gate` workflow requires:

1. `OPENAI_API_KEY` for Codex CLI.
2. One Claude credential, in this precedence order:
   - `ANTHROPIC_API_KEY`, or
   - `CLAUDE_CODE_OAUTH_TOKEN` generated by `claude setup-token` for CI/subscription use.

If both Claude credentials are present, `ANTHROPIC_API_KEY` takes precedence.

Never paste these values into repository files, PR comments, issues, artifacts, logs, or chat messages.

## Security boundary

- Workflow is manual for provider parity; ordinary PR runs skip paid provider calls.
- Checkout credentials are not persisted.
- Codex runs read-only with ephemeral execution and ignored user/rule config.
- Claude runs `--safe-mode`, plan permission mode, Read-only tool allowlist, Edit/Write/Bash denied, no session persistence, max 3 turns, and USD 1.00 budget cap.
- Evidence artifacts contain normalized outputs and auth mode name only, never secret values.
- No EVENTO or sibling repository is read or mutated by the provider fixture.

## Owner run procedure

After secrets are stored in GitHub Actions for this repository:

1. Open Actions → `Empire Live Proof Gate`.
2. Choose `Run workflow` on `feat/platform-intelligence-2026-08`.
3. Set `run_provider_parity = true`.
4. Run once.
5. Require `codex-claude-live-parity` PASS and inspect `empire-provider-parity-evidence` before any promotion decision.
