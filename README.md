## Mission

Turn ambitious product ideas into verifiable, secure, maintainable, deployable systems through a coordinated multi-agent engineering empire.

## Operating model

The repository is the source of truth. Every agent must:

1. Read `AGENTS.md` before making changes.
2. Inspect existing architecture, decisions, tests, and verification evidence.
3. Work in small, reviewable increments.
4. Never claim completion without evidence.
5. Preserve security, privacy, accessibility, performance, and maintainability.

## Quality doctrine

A feature is not complete when code exists. It is complete only when:

- acceptance criteria are satisfied;
- tests and validation pass;
- security and performance risks are addressed;
- documentation is updated;
- verification evidence is recorded;
- rollback or recovery is understood.
