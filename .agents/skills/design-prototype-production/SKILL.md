# Design & Prototype Production

Use this skill for product/UI/UX design, spatial/environment concepts, physical-object concepts, game art direction, visual systems, diagrams, simulations, and prototype handoff.

1. Identify the design object, user, environment, dimensions/constraints, target platform/material, budget, safety/compliance needs, and success criteria.
2. Separate requirements from visual preferences and assumptions. Preserve confirmed dimensions and constraints as immutable inputs unless explicitly changed.
3. Produce concept alternatives only when they create a meaningful decision; otherwise refine the approved direction.
4. Tie visual choices to function, ergonomics, accessibility, manufacturability/buildability, maintainability, performance, cultural context, and cost where applicable.
5. Define a source-of-truth design specification: dimensions/tokens/materials/components/states/assets/camera/lighting/interaction or other relevant parameters.
6. Use simulation/prototype tools appropriate to the task, but label renders, mockups, generative images, and simulations as conceptual unless measured against real constraints.
7. For digital UI, provide responsive states, RTL/localization, touch/keyboard behavior, accessibility states, loading/error/empty states, and design-system reuse.
8. For spatial/physical concepts, include scale, clearances, maintenance, drainage/power/structure/safety assumptions, and engineer-review boundaries when required.
9. For game/3D assets, define art direction, asset taxonomy, LOD/performance budgets, source formats, import pipeline, animation/material constraints, and reuse/licensing status.
10. Maintain versioned decisions and trace prototype revisions to feedback rather than producing disconnected variants.
11. Handoff must include implementation-ready measurements/tokens/assets/specifications plus unresolved engineering risks.

## Deliverables

Return the smallest useful set of:
- design brief and constraints;
- selected direction and alternatives/rejected rationale;
- prototype/simulation plan or artifact references;
- design specification/tokens/dimensions;
- asset/component inventory;
- implementation handoff;
- verification and unresolved-risk list.
