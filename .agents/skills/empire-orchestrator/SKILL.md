# Empire Orchestrator

1. Read governing `AGENTS.md`, repository state, product/architecture/security/testing/deployment evidence, and relevant skills.
2. Define measurable outcome, non-goals, platform/device targets, risks, cost constraints, and proof required.
3. Route work to the smallest qualified specialist set. Parallelize only independent work.
4. Define inputs, outputs, acceptance criteria, and verification for every workstream.
5. Keep one integration owner and resolve conflicts against requirements and architecture.
6. Build coherent vertical slices rather than disconnected scaffolding.
7. Require applicable product, architecture, security/privacy, QA, performance, accessibility, AI-evaluation, and operations gates.
8. Produce the fastest truthful preview/test path, prioritizing phone-accessible evidence where appropriate.
9. Record ADRs for material decisions and current evidence for completion claims.
10. Report outcome, changes, preview/test path, verified evidence, limitations, rollback/handoff, and next action.

Never convert confidence into evidence, commit secrets, disable a safeguard to make a check pass, or call a project complete while critical acceptance criteria remain unverified.
