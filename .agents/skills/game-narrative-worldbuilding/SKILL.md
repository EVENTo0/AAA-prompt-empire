# Game Narrative & Worldbuilding

Use this skill when a game, simulation, interactive story, or transmedia product needs an original narrative foundation tied to actual gameplay and production constraints.

1. Start from player fantasy, target audience, platform, genre, session length, gameplay loop, rating target, cultural constraints, production scale, and monetization boundaries.
2. Build an original premise and thematic pillars. Do not imitate a living author's distinctive style or copy protected characters, worlds, scenes, dialogue, quest structures, or recognizable story beats.
3. Connect narrative to mechanics: every major lore element, faction, conflict, progression beat, and quest family should have a gameplay consequence or production reason to exist.
4. Define world rules, chronology, geography, cultures/factions, technology/magic rules, economy, conflict, and information asymmetry before generating large volumes of lore.
5. Design characters with goals, constraints, relationships, contradictions, gameplay roles, and arc states. Avoid biography volume that never appears in play.
6. Create quest/story content as reusable structures: setup → player choice/action → system response → consequence → state change → recovery/failure path.
7. For branching narratives, define state variables and convergence strategy so branch count remains testable and affordable.
8. Separate canon, optional lore, procedural content, placeholders, and speculative ideas. Version material decisions.
9. Support Arabic/English localization, RTL constraints, naming checks, cultural review, age-rating concerns, accessibility, and voice-over budget when relevant.
10. Produce implementation-facing artifacts: narrative bible, character/faction sheets, quest/state tables, dialogue intent, cinematic requirements, asset dependencies, acceptance criteria, and testable continuity rules.
11. For AI-generated narrative at runtime, add safety/content boundaries, canonical retrieval sources, structured outputs, deterministic state ownership, evaluation sets, and fallback behavior.
12. Review for originality, internal consistency, scope, gameplay relevance, localization risk, and production cost before marking narrative work ready.

## Deliverables

Return only the artifacts needed for the current slice, such as:
- premise/theme pillars;
- world/faction/character model;
- quest or chapter structure;
- branching/state model;
- narrative-to-gameplay dependency map;
- localization/content-rating notes;
- implementation and verification handoff.
